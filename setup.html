إعداد كلمة مرور الملخص الصباحي

هذه الصفحة تعمل على جهازك فقط ولا ترسل كلمة المرور إلى أي مكان. تُنشئ ملف key.json يحتوي على مفتاح فك التشفير مقفلًا بكلمة المرور.

  1. اكتب كلمة مرور قوية (12 حرفًا على الأقل) مرتين، ثم اضغط "إنشاء الملف".
  2. سيُحمَّل الملف key.json على جهازك.
  3. ارفعه إلى المستودع KmeficMarketing/Daily-Hub على GitHub: Add file ثم Upload files، في المجلد الرئيسي، ثم Commit changes.
  4. احفظ كلمة المرور في مكان آمن. إذا ضاعت لا يمكن فتح الأرشيف.

This page runs only on your device and never sends the password anywhere. It creates key.json, which holds the decryption key sealed with your password. Upload it to the root of KmeficMarketing/Daily-Hub on GitHub (Add file → Upload files → Commit changes). Keep the password safe: if it is lost, the archive cannot be opened.
